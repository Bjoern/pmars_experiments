Browser debugger commands

Click a core cell to pause and list from that address; right-click lists up to it. Choose the line count, page through memory, or follow a warrior's next instruction.

list / l address[,end] (also pc and .), step / s [count], go / g, pause, reset, progress, registers, alive, tproc, help.

Adapted aliases from pmars.mac and mw.mac: macro f5, f7, f8 step once and follow the first warrior with 13 lines; f9 continues; mousel / mousem / mouser refresh the listing; up / down / pgup / pgdn navigate. F5/F7/F8/F9, arrows, Page Up/Down and Escape work outside editable controls.

This is a browser subset, not the full cdb macro interpreter. Shell/file commands, macro loops, breakpoints, and operand-pointer macros are not implemented.
